## 导入与说明

在 ProcessOn 的“我的文件”页面选择“新建”→“导入”，优先选择同名 .mm 文件；也可导入 .opml 备用文件。导入后可以修改布局、拖动节点和编辑名称。

官方支持格式说明：[文件导入](https://www.processon.com/support/file-import)。本地检查 XML 与网站导航一致性，未在 ProcessOn 账号内实际导入。
