## 安装模板

使用与发布 wheel 兼容的独立 Python 环境。将下方示意路径替换为实际发布文件；这些命令不代表已经确认版本兼容性。

```bash
python -m pip install "/path/to/your-sdk.whl"
python -m pip check
```
