# BodyOS SDK

BodyOS 是通过 `.whl` 文件分发的 Python SDK，不是完整操作系统。它提供开发者接口，设备侧控制仍承担自身的安全职责。

- [安装与配置](installation-and-configuration.md)
- [基本使用](basic-usage.md)
- [架构与安全边界](architecture-and-safety-boundary.md)

展会 az_sdk 的 wheel 名称、设备路径及数据读取流程见[读取外骨骼本体](../examples/read-exoskeleton.md)，不能据此推断其他 SDK 版本的兼容性。
