# Basic Usage

Status: To be completed after the actual package and interface contract are available. The steps below are an authoring outline, not executable API instructions.

## First-use outline

1. Import the confirmed package name.
2. Configure and connect to the supported device using its documented connection method.
3. Read device identity, status, and telemetry before requesting control.
4. If control is required, follow approved safety and authorization procedures.
5. Close the connection and document failure handling.
