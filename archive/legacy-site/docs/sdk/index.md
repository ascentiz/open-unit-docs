# BodyOS SDK

BodyOS is a Python SDK distributed as a `.whl` file, not a complete operating system. It exposes developer-facing capabilities while device-side control retains its safety responsibilities.

- [Installation and Configuration](installation-and-configuration.md)
- [Basic Usage](basic-usage.md)
- [Architecture and Safety Boundary](architecture-and-safety-boundary.md)

For the exhibition-specific az_sdk wheel name, device path, and data-reading workflow, see [Read Exoskeleton Data](../examples/read-exoskeleton.md). That guide does not establish compatibility for other SDK releases.
