# 架构与安全边界

BodyOS 是面向开发者的 SDK。安装或调用它，不会替代设备侧安全控制，也不意味着获得无限制的执行器访问权限。

## 职责边界

- SDK：面向开发者的连接、数据访问及受约束的控制请求；具体模块等待发布资料确认。
- 设备侧控制：按照现有平台模型，保留最终指令接纳与安全约束执行职责。
- 应用程序：遵循授权、运行限制、遥测时效性及故障处理要求。

不能用 SDK 检查替代设备侧安全保护。发布控制示例前，应明确真实的指令拒绝、超时／断连行为及经批准的停止流程。

现有背景资料：[平台边界](../architecture/platform-boundary.md)和[安全模型](../architecture/safety-model.md)。这些属于概念说明，不是认证声明。
