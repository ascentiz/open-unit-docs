# 开发套件

Open Unit 开发套件是基于 Ascentiz 平台开发与验证软件的参考环境。

## 参考假设

当前参考配置假设：

- 使用 Raspberry Pi CM5 级别的 Open Unit 计算模块
- 使用 Linux 用户空间服务进行编排、诊断及应用逻辑执行
- 通过设备本地接口与 Exoskeleton Unit 交换命令、状态及遥测
- 提供适合实验室使用的 SSH、日志采集及服务重启访问方式

随着产品硬件定型，这些假设可能变化，但可以作为早期软件开发的参考基线。

## 最低软件要求

Open Unit 环境应提供：

- 核心平台服务的进程管理器
- 控制与遥测交换的传输层
- 设备健康状态及应用诊断的日志访问方式
- 可复现的实验应用部署方式

## 推荐主机工具

对大多数团队而言，以下主机工具即可满足初期需求：

- Python 3.11+
- `ssh` 和 `rsync`，或其他部署工具
- `git`
- 与设备配置匹配的串口或网络诊断流程

## 启动检查清单

运行应用前，请确认：

- 设备正常启动
- 平台服务健康
- 已检测到 Exoskeleton Unit
- 不存在活动故障
- 遥测数据流可读取
- 会话默认处于未使能（`unarmed`）状态

如果任何检查失败，在明确故障原因之前，不要继续运动相关测试。
