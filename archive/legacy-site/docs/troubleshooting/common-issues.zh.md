# 常见问题

状态：初步检查清单；产品专用错误码及已验证的解决方案待补充。

## 安装问题

确认安装与运行使用同一个 Python 环境。检查正式 wheel 的 Python／平台／架构要求及依赖检查结果。保留完整错误信息；不要通过修改 wheel 文件名绕过兼容性检查。

## 连接与遥测问题

检查经批准的[供电与连接说明](../hardware/power-and-connection.md)、实际连接配置、设备身份、SDK 版本及遥测是否更新。不要为了处理指令拒绝而绕过设备侧安全保护。

如出现异常机械或电气行为，应遵循经批准的停止流程并联系硬件支持，不要自行尝试维修。问题未解决时，整理[日志与反馈](logs-and-feedback.md)。
