# Common Issues

Status: Initial checklist; product-specific error codes and confirmed resolutions are still to be added.

## Installation

Confirm that installation and execution use the same Python environment. Check the released wheel's Python/platform/architecture requirements and the dependency report. Keep the complete error text; do not rename a wheel to bypass compatibility checks.

## Connection and telemetry

Check the approved [power and connection instructions](../hardware/power-and-connection.md), actual connection configuration, device identity, SDK version, and whether telemetry is current. Do not bypass device-side protections to resolve a rejected command.

If abnormal mechanical or electrical behavior occurs, follow the approved stop procedure and seek hardware support; do not improvise repairs. Prepare [Logs and Feedback](logs-and-feedback.md) when the issue remains unresolved.
