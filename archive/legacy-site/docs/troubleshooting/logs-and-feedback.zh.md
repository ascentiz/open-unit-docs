# 日志与反馈

提供可复现的问题报告，不要直接上传未经筛选的敏感日志。SDK 专用日志开关及日志路径待确认。

## 报告清单

- SDK／wheel 版本、Python 环境、主机操作系统及硬件修订版本。
- 预期结果、实际结果、最小复现步骤及包含时区的时间记录。
- 相关完整错误信息及脱敏后的日志片段。
- 连接方式，以及操作属于只读还是申请控制。

移除凭据、访问令牌、个人信息及私有实验数据，遵循所在组织的数据规定。现有[反馈说明](../community/feedback.md)提供报告背景，[参与贡献](../community/contributing.md)说明文档修改方式。
