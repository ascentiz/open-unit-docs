# 教程

本节提供将平台概念与实际操作结合的引导流程。

## 教程应帮助完成的任务

每篇教程应帮助开发者完成一项实际任务：

- 启动并检查新设备
- 验证命令与遥测路径
- 部署实验应用
- 在明确假设的前提下复现实验室流程

## 编写方式

后续教程应保持明确且实用：

- 列出前置条件
- 定义成功标准
- 展示预期输出
- 明确说明安全假设
