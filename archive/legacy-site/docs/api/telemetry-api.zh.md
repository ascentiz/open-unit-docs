# 遥测 API

遥测是理解设备状态、验证实验及调试集成的主要接口。

## 遥测类别

Open Unit 应至少提供以下可被机器读取的遥测数据：

- 关节状态
- 执行器状态
- 惯性与辅助传感数据
- 安全及故障状态
- 会话与命令元数据
- 平台健康状态及资源使用情况

## 数据流示例

```json
{
  "timestamp": "2026-04-17T09:20:31.240Z",
  "topic": "joint_state",
  "sequence": 10428,
  "payload": {
    "knee": {
      "position_rad": 0.18,
      "velocity_rad_s": -0.04,
      "torque_nm": 5.7,
      "temperature_c": 42.3
    }
  }
}
```

## 设计要求

遥测接口应：

- 尽可能在数据源处添加时间戳
- 明确单位与坐标系
- 能够处理样本丢失
- 便于 Python 及其他常用机器人工具使用

## 建议主题

| 主题 | 用途 |
| --- | --- |
| `joint_state` | 位置、速度、扭矩及温度状态 |
| `imu` | 身体或肢段运动数据 |
| `session_state` | 当前命令权限及租约状态 |
| `fault_state` | 活动故障及恢复状态 |
| `system_health` | CPU、内存、存储、传输及进程健康状态 |

## 计划扩展

后续版本可以补充：

- 数据保留与回放指南
- 结构定义（schema）
- 主题级服务质量（QoS）建议
- 面向云端或实验室数据管线的采集器示例
