# 机械结构：Exo Belt

Exo Belt 是系统的外骨骼腰带与机械承载部分。本页先建立正式文档框架，用于后续补充经过确认的机械结构、装配和佩戴资料。

!!! info "当前状态"
    本页为框架页。除“Exo Belt 是系统机械组成部分”外，具体结构名称、尺寸、材料、载荷和装配步骤均需等待机械或开发团队确认。
