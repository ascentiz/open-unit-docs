## 首次使用提纲

1. 导入已确认名称的软件包。
2. 根据文档规定的连接方式，配置并连接支持的设备。
3. 申请控制前先读取设备身份、状态和遥测。
4. 如需控制，遵循经批准的安全与授权流程。
5. 关闭连接，并说明失败处理方式。
