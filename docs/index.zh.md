# BodyOS

**BodyOS** 是面向 Ascentiz 外骨骼平台开发者的 Python/C++ SDK，不是完整的操作系统。

它面向需要从硬件集成走向应用机器人研究的团队：

- 开发设备端应用的嵌入式与控制工程师
- 验证传感、意图估计和辅助策略的研究人员
- 开展步态及人机交互研究的高校实验室
- 集成感知、分析或设备群管理工具的生态合作伙伴

!!! note "平台状态"
    当前文档描述的是早期开发者平台。在发布正式的版本承诺之前，接口、硬件细节及软件契约均应视为仍在演进。

## 平台概览

Ascentiz 平台有意划分为两个层级：

| 层级 | 职责 | 迭代节奏 |
| --- | --- | --- |
| Exoskeleton Unit | 实时驱动、设备保护、电机控制及硬性安全约束执行 | 受控且审慎 |
| Open Unit | 开发者应用、高层控制逻辑、数据处理、实验工具及外部集成 | 更快速的迭代 |

这种划分使开发者能够基于平台开展开发，而不绕过设备级安全层。

## 设计原则

1. 安全关键行为应靠近执行器，不依赖无法保证确定性执行的用户代码。
2. 开发流程应便于使用标准机器人工具进行测试、检查和扩展。
3. 科研集成应能在不同实验室及试点部署中复现。
4. API 应明确表达状态、权限及故障模式。
