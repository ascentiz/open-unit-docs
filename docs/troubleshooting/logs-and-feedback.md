# Logs and Feedback

Provide a reproducible report, not an unfiltered dump of sensitive logs. SDK-specific logging switches and log paths are still to be confirmed.

## Report checklist

- SDK/wheel version, Python environment, host OS, and hardware revision.
- Expected result, actual result, minimal reproduction steps, and timestamps with timezone.
- Complete relevant error messages and sanitized log excerpts.
- Connection method and whether the operation was read-only or requested control.

Remove credentials, access tokens, personal information, and private experiment data. Follow your organization's data policy. Existing [Feedback guidance](../community/feedback.md) describes reporting context; [Contributing](../community/contributing.md) covers documentation changes.
