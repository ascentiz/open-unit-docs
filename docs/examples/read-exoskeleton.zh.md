# 读取外骨骼本体

通过 AZ 算力盒读取 AZ-H 外骨骼的状态及传感器数据。本示例依据 **AZ算力盒展会版本操作说明1.docx** 整理，适用于文档中的展会配置，包括已安装的 Python SDK 与 Windows 数据监控软件，不是适用于所有 BodyOS 版本的通用安装指南。

!!! warning "开机过程可能发生动作"
    数据读取不请求动作控制，但 AZ-H 开机会进行穿戴检测，过程中电机可能运动。请由受训操作人员遵循经批准的穿戴及开机流程。本示例不收录展会文档中非穿戴情况下人工限制电机转动的操作，不得绕过穿戴检测或设备侧安全保护。

## 所需设备与软件

- 一台 AZ 算力盒及与之连接的 AZ-H 外骨骼。
- 一台 Windows 笔记本，用于网络连接与数据监控软件。
- 算力盒无线热点，或配套 HRS IX 网线用于有线连接。
- 展会算力盒上已经安装的 SDK 与 demo。

算力盒连接 AZ-H **没有闪电标识的 USB Type-C 接口**。该展会版本中，算力盒只有电源键可用，加、减及模式切换键尚未生效。连接、穿戴与开机请遵循经批准的硬件操作流程。

原文以 AZ-H 背包指示灯变绿作为穿戴检测通过的标志；检测不通过时，AZ-H 不对外输出数据。此时应停止并联系设备操作人员，不要强行建立数据连接。

## 将电脑连接到算力盒

| 连接方式 | 算力盒地址 | 电脑侧准备 |
| --- | --- | --- |
| 无线 | `10.42.0.1` | 连接名称以 CM5 开头的算力盒 Wi-Fi 热点；非有线配置使用 `dhcp_ip_set.bat`。 |
| 有线 | `192.168.10.1` | RJ45 端连接电脑，IX 端连接算力盒；执行 `static_ip_set.bat`。 |

展会热点名称为 `CM5-0B2D`，其他设备的名称可能不同。连接凭据请向设备管理员获取。两个批处理脚本位于 Windows 桌面的 `dist-exe` 文件夹，本仓库不包含这些脚本。

切换连接方式后，需要使用对应脚本，并修改目标地址。原文建议无线连接稳定时优先使用无线方式；网线会限制电脑与算力盒之间的距离。上述 IP 与脚本属于展会配置，不是通用硬件默认值。

## 使用 Python SDK 读取数据

SDK 在 **Linux ARM64 算力盒上运行**，不是在 Windows 数据监控软件中运行。原文提供的版本信息为：

- Wheel：`az_sdk-1.4.0-cp314-cp314-linux_aarch64.whl`。
- 导入名称：`az_sdk`。
- 所在目录：`/home/bodyos/cm5-az/spi_master/sdk`。
- 配套示例：`demo.py`。

从 wheel 文件名可知，该文件面向 CPython 3.14 和 Linux AArch64；不能据此认定它支持 Windows、macOS、其他 CPU 架构或其他 Python 版本。原文说明，展会算力盒已完成 SDK 安装。

### 1. 通过 SSH 登录

无线连接：

```bash
ssh bodyos@10.42.0.1
```

有线连接：

```bash
ssh bodyos@192.168.10.1
```

使用管理员提供的凭据。公开文档不写入密码。

### 2. 检查运行环境

在算力盒终端中，使用已安装展会 SDK 的 Python 环境：

```bash
cd /home/bodyos/cm5-az/spi_master/sdk
python3 --version
python3 -c "import az_sdk; print(az_sdk.__file__)"
```

确认 Python 与 wheel 匹配，且能够成功导入软件包。如导入失败，应先检查运行环境，不要直接重装。

### 3. 运行配套 demo

先查看配套的 `demo.py`，确认它与该展会版本一致，且仅包含预期的数据读取及本地 CSV 记录操作，再执行：

```bash
python3 demo.py
```

原文列出 demo 已实现的操作：连接、状态获取、传感器数据获取、传感器数据写入 CSV、断开连接。这里的“传感器数据写入”是指**保存本地 CSV 文件，不是向传感器或执行器写入控制指令**。

上传的 Word 不包含 demo 源码、函数签名、参数、返回字段或 CSV 保存位置。调用顺序、输出及资源清理以实际 demo 为准，本页不编造 `az_sdk` API，也不将其他规划中的接口描述为已可用。

## 使用 Windows 软件查看数据

这是另一种数据查看方式；原文没有说明它能否与 SDK demo 同时运行。

1. 按上文完成网络连接。
2. 打开桌面 `dist-exe` 文件夹，运行 `机械臂数据监控.exe`。这是原文中的软件文件名，本示例实际读取的是 AZ-H 数据。
3. 在 Microsoft Edge 界面中打开标题栏的“连接配置”。
4. 无线方式选择 `10.42.0.1`，有线方式选择 `192.168.10.1`，然后连接。
5. 返回“数据监控”，查看数据。

原文没有提供服务器端口、命令行选项或其他字段，不在此补写。

## 确认数据与排查问题

网络连接成功不等于已收到本体实时数据。检查返回状态，以及数据索引是否持续推进。设备静止时传感器值可能稳定；索引持续不变则需要排查。

- 没有数据：检查穿戴检测是否通过、算力盒与 AZ-H 的合规连接，以及目标网络地址。
- 切换网络后地址不匹配：使用对应电脑脚本，并更新软件的连接配置。
- 导入失败：确认是在算力盒上、使用 SDK 所在的 Python 环境运行。
- 数值和索引始终不变：原文指出这可能是算力盒与 G4 之间通信异常；针对这种情况，SSH 手动重启程序不是有效解决方式。请由设备操作人员按照经批准的停止及重上电流程处理。

原文说明，设备通信程序、TCP 服务器及网线检测程序会开机自启。前两项具有监控机制，崩溃后会在三秒内重新运行，一般无需操作人员手动启动。进程重新运行不等于设备通信已经恢复。

结束时使用 demo 规定的断开连接及清理方式。仍有问题时，按照[日志与反馈](../troubleshooting/logs-and-feedback.md)整理脱敏后的版本、时间及错误信息。
