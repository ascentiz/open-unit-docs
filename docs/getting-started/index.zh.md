# 快速入门

从本节开始了解 Exo Belt、B-core Pi 1 和 BodyOS Python SDK，并安全地准备首次集成。BodyOS 通过 `.whl` 软件包分发，不是操作系统。

## 建议流程

大多数团队可按以下顺序使用平台：

1. 启动并检查 Open Unit 开发套件。
2. 在不发送运动命令的情况下检查系统状态与遥测。
3. 建立会话，并确保安全状态明确可见。
4. 通过安全门控流程发送低风险命令。
5. 验证硬件与软件假设之后，再开展闭环实验。

## 开始之前

请准备：

- Open Unit 开发设备或评估套件
- 运行已批准固件的兼容 Exoskeleton Unit
- 设备的网络或有线调试访问方式
- 配备与实际 SDK wheel 兼容的 Python 环境的主机工作站；支持版本仍待确认
- 对实验室或组织安全审查流程的了解
