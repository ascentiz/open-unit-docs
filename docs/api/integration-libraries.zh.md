# Integration Libraries（规划中）

BodyOS 后续将提供集成库，帮助开发者在 B-core Pi 1 上更方便地接入第三方传感器与外部设备。本页用于记录规划范围、交付状态和未来的使用文档入口。

!!! info "当前状态"
    Integration Libraries 尚处于规划阶段。只有已交付并明确列入支持清单的库、设备和接口才属于正式支持范围；本页中的分类不代表当前已经提供对应能力。

## 规划范围

### 第三方传感器

后续可在此记录：

- IMU、力传感器、压力传感器等设备的适配库
- 设备发现、初始化和连接方法
- 数据结构、单位、时间戳与采样频率
- 数据同步、缓存和异常状态处理
- 与 BodyOS 数据流的组合使用方式

### 外部设备

后续可在此记录：

- 外部控制器、采集设备和交互设备的适配库
- 通信方式、连接步骤与权限要求
- 指令、状态和事件接口
- 设备断开、重连与错误处理
- 已验证的设备型号和软件版本

## 单个集成库的文档要求

每个正式交付的集成库至少需要说明：

1. 支持的设备、型号和版本。
2. 运行环境、依赖与安装方式。
3. B-core Pi 1 的连接和配置要求。
4. 初始化、读取、控制和关闭流程。
5. API、数据结构、单位及错误行为。
6. 可运行示例和安全注意事项。
7. 已知限制与兼容性范围。

## 开发边界

- 集成库运行在 B-core Pi 1 的用户开发环境中。
- 集成库用于扩展第三方传感器或外部设备，不开放 Exoskeleton Unit 的内部硬件和设备驱动。
- 外骨骼数据读取与控制仍通过公开的 BodyOS SDK/API 完成。
- 未列入正式支持清单的设备不应被描述为兼容或可直接使用。
