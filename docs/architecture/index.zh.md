# 系统架构

Ascentiz 平台有意划分为两个层级：

1. **Exoskeleton Unit**：连接执行器和设备传感器的嵌入式实时控制与安全层
2. **Open Unit**：面向开发者的计算层，承载应用、科研逻辑、数据管线及外部集成

这是平台最重要的概念。

## 为什么采用分层

外骨骼开发中的两类需求往往存在张力：

- 设备行为必须可预测、有界且安全
- 开发流程需要快速迭代、可观测性及实验空间

Ascentiz 架构通过将快速变化的应用软件与最底层约束执行层分离，协调这两类需求。

## 分层职责

| 能力 | Exoskeleton Unit | Open Unit |
| --- | --- | --- |
| 电机换相及执行器控制环 | 是 | 否 |
| 安全联锁与设备保护 | 是 | 否 |
| 看门狗与故障处理 | 是 | 仅协助报告 |
| 高层辅助逻辑 | 否 | 是 |
| 实验软件与自定义算法 | 否 | 是 |
| 遥测日志与云端集成 | 有限支持 | 是 |
| 第三方应用 | 否 | 是 |

## 实际影响

- 安全运行边界的最终决定权仍在 Exoskeleton Unit
- Open Unit 可以请求设备行为，但不能在运行时重新定义硬性安全策略
- 应用必须将降级状态与命令拒绝视为正常运行中需要处理的情况
